# Longest Palindromic Substring (LeetCode 5)

**Pattern:** Expand Around Center (Two Pointers)

---

# 1. Problem Statement

Given a string `s`, return the **longest palindromic substring**.

A **palindrome** reads the same forwards and backwards.

A **substring** consists of contiguous characters.

### Constraints

* `1 <= s.length <= 1000`
* `s` consists of English letters and digits.
* Need the longest contiguous palindrome.

# 4. Intuition & Pattern Recognition

### Signals

Whenever you see

* Longest palindromic substring
* Contiguous substring
* String length around 1000

Think:

> **Expand Around Center**

### Why?

Every palindrome has a center.

There are only two possibilities:

* Odd length palindrome

```text
aba

Center = b
```

* Even length palindrome

```text
abba

Center = between b and b
```

There are only **2N−1 possible centers**, so we simply expand from each.

### Interview Thinking

```text
Instead of checking every substring,

I'll choose every possible center.

Expand left and right while characters match.

Track the longest palindrome found.
```

# 7. Optimal Solution (Expand Around Center)

### Idea

For every index:

* Expand for odd palindrome `(i, i)`
* Expand for even palindrome `(i, i+1)`

Keep the longest.

### Python

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        res = ""
        resLen = 0

        for i in range(len(s)):

            # Odd length palindrome
            l, r = i, i
            while l >= 0 and r < len(s) and s[l] == s[r]:
                if (r - l + 1) > resLen:
                    res = s[l:r + 1]
                    resLen = r - l + 1
                l -= 1
                r += 1

            # Even length palindrome
            l, r = i, i + 1
            while l >= 0 and r < len(s) and s[l] == s[r]:
                if (r - l + 1) > resLen:
                    res = s[l:r + 1]
                    resLen = r - l + 1
                l -= 1
                r += 1

        return res
```

### Complexity

```text
Time  : O(N²)

Space : O(1)
```

# Why Not Sliding Window?

Many candidates mistakenly think:

```text
Longest substring

↓

Sliding Window
```

This **does not work**.

A palindrome is **not a monotonic property**.

Example:

```text
aba   ✓ palindrome

Add one character

abac   ✗ not palindrome

Remove left

bac    ✗ not palindrome
```

Unlike duplicate characters or sums, there is no simple way to shrink or expand a window while preserving palindrome validity.

That's why **Expand Around Center** is the preferred interview solution.

# DP Solution (Alternative)

Define:

```text
dp[i][j] = True

if s[i...j] is a palindrome
```

Transition:

```text
dp[i][j] =
    s[i] == s[j]
    AND
    (j - i < 3 OR dp[i+1][j-1])
```

### Complexity

```text
Time  : O(N²)

Space : O(N²)
```

Useful when you need to answer multiple palindrome queries, but for this problem, **Expand Around Center** is simpler and uses constant extra space.

# Key Interview Takeaways

* **Pattern:** Expand Around Center.
* **Core Insight:** Every palindrome has a center.
* **Centers to Check:** `2N - 1` (N odd + N−1 even).
* **Algorithm:** Expand outward while characters match.
* **Time Complexity:** **O(N²)**.
* **Space Complexity:** **O(1)**.
* **Interview Preference:** Expand Around Center is cleaner than DP and much easier to explain.

For comparison with your previous revision sheet on **Longest Substring Without Repeating Characters**, note that this problem uses a completely different pattern. The previous problem was solved with a **Variable Size Sliding Window** because "unique characters" is a monotonic window property, whereas palindrome validity is not.
