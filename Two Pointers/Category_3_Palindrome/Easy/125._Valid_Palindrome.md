# Valid Palindrome (LeetCode 125)

## 1. Problem Statement

Given a string `s`, determine whether it is a **palindrome** after:

* Converting all uppercase letters to lowercase.
* Removing all non-alphanumeric characters.

Return `true` if it is a palindrome, otherwise return `false`.

A palindrome reads the same forwards and backwards.

### Constraints

* `1 <= s.length <= 2 × 10^5`
* String may contain:

  * Uppercase/lowercase letters
  * Digits
  * Spaces
  * Punctuation/special characters
* Aim for **O(N)** time.

### Signals

Whenever you see:

* Check if a string is palindrome
* Ignore certain characters
* Compare from both ends

Think:

> **Two Pointers**

Why?

Instead of reversing the string or creating another copy, compare the leftmost and rightmost valid characters directly.

# 6. Brute Force

Create a cleaned string.

```
Keep only letters and digits.

Convert to lowercase.

Reverse it.

Compare.
```

### Python

```python
class Solution:
    def isPalindrome(self, s: str) -> bool:

        cleaned = ""

        for ch in s:
            if ch.isalnum():
                cleaned += ch.lower()

        return cleaned == cleaned[::-1]
```

### Complexity

```
Time : O(N)

Space: O(N)
```

# 7. Optimal Solution (Two Pointers)

### Idea

Maintain:

```
left
right
```

Move both pointers inward.

* Skip invalid characters.
* Compare lowercase versions.
* Stop immediately if mismatch occurs.

### Python

```python
class Solution:
    def isPalindrome(self, s: str) -> bool:

        left = 0
        right = len(s) - 1

        while left < right:

            # Skip invalid characters from the left
            while left < right and not s[left].isalnum():
                left += 1

            # Skip invalid characters from the right
            while left < right and not s[right].isalnum():
                right -= 1

            # Compare characters ignoring case
            if s[left].lower() != s[right].lower():
                return False

            left += 1
            right -= 1

        return True
```

### Complexity

```
Time  : O(N)

Space : O(1)
```

# Key Interview Takeaways

* **Pattern:** Two Pointers.
* **Invariant:** Compare only valid (alphanumeric) characters.
* **Rule:** Skip invalid characters, compare lowercase values, and move inward.
* **Optimization:** No extra string construction is needed.
* **Complexity:** **O(N)** time and **O(1)** extra space.
