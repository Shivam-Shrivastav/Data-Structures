# Remove Duplicates from Sorted Array (LeetCode 26)

**Pattern:** Two Pointers (Read Pointer + Write Pointer)

---

# 1. Problem Statement

Given a **sorted** integer array `nums`, remove the duplicates **in-place** such that each unique element appears only once.

The relative order of the elements should remain the same.

Return the number of unique elements `k`, where the first `k` elements of `nums` contain the unique values.

You **must not** allocate another array.

### Constraints

* `1 <= nums.length <= 3 × 10⁴`
* `-100 <= nums[i] <= 100`
* `nums` is sorted in **non-decreasing order**
* Must modify the array **in-place**
* Extra space should be **O(1)**

### Signals

Whenever you see

* Sorted array
* Remove duplicates
* In-place modification
* Constant extra space

Think:

> **Two Pointers**

Why?

Since the array is sorted,

```text
Duplicates are always adjacent.
```

So we only need to compare the current number with the last unique number.

# 6. Brute Force

Create another array.

```text
result = []

For every element

If different from previous

append it
```

Finally copy it back.

### Python

```python
class Solution:
    def removeDuplicates(self, nums):
        if not nums:
            return 0

        result = [nums[0]]

        for i in range(1, len(nums)):
            if nums[i] != nums[i - 1]:
                result.append(nums[i])

        nums[:len(result)] = result

        return len(result)
```

### Complexity

```text
Time  : O(N)

Space : O(N)
```

# 7. Optimal Solution (Two Pointers)

### Idea

Maintain

```text
write

read
```

* `read` scans every element.
* `write` points to the next location where a unique value should be placed.

Whenever

```text
nums[read] != nums[write-1]
```

copy it.

---

### Python

```python
class Solution:
    def removeDuplicates(self, nums):

        if not nums:
            return 0

        write = 1

        # Read every element starting from index 1
        for read in range(1, len(nums)):

            # Found a new unique element
            if nums[read] != nums[write - 1]:
                nums[write] = nums[read]
                write += 1

        return write
```

### Complexity

```text
Time  : O(N)

Space : O(1)
```

# Key Interview Takeaways

* **Pattern:** Two Pointers (Read + Write Pointer).
* **Key Observation:** The array is **sorted**, so duplicates are adjacent.
* **Invariant:** `nums[0...write-1]` always contains all unique elements seen so far.
* **Rule:** Scan with `read`; whenever a new value is found, write it at `write` and increment `write`.
* **Complexity:** **O(N)** time and **O(1)** extra space.
* **Interview Tip:** Whenever you hear **"sorted array + in-place + remove duplicates"**, think **read/write pointers** immediately.
