# Two Sum II – Input Array Is Sorted (LeetCode 167)

**Pattern:** Two Pointers

---

# 1. Problem Statement

You are given a **1-indexed** array `numbers` sorted in **non-decreasing order** and a target integer `target`.

Find **two numbers** such that:

* They add up to `target`.
* Return their **1-based indices** `[index1, index2]`.
* There is **exactly one solution**.
* You **cannot use the same element twice**.

The array is already **sorted**, which is the key observation.

### Constraints

* `2 <= numbers.length <= 3 × 10^4`
* `-1000 <= numbers[i] <= 1000`
* `numbers` is sorted in non-decreasing order.
* Exactly one valid answer exists.
* Extra space should ideally be **O(1)**.

# 4. Intuition & Pattern Recognition

### Signals

Whenever you see:

* Sorted array
* Pair of elements
* Sum equals target
* O(1) extra space preferred

Think:

> **Two Pointers**

---

### Why does it work?

Since the array is sorted:

* If the current sum is **too small**, increasing the left pointer increases the sum.
* If the current sum is **too large**, decreasing the right pointer decreases the sum.

No combinations are skipped because the sorted order guarantees this behavior.

---

### Interview Thinking

```text
The array is sorted.

I don't need HashMap.

Start from both ends.

If sum is small,
increase left.

If sum is large,
decrease right.

Eventually I'll reach the only valid pair.
```

```python
            return [i + 1, j + 1]
```

### Complexity

```text
Time : O(N²)

Space : O(1)
```

# 7. Optimal Solution (Two Pointers)

### Idea

Maintain:

```text
left = 0
right = n-1
```

While:

* Sum < target → move left
* Sum > target → move right
* Sum == target → answer found

---

### Python

```python
class Solution:
    def twoSum(self, numbers: List[int], target: int) -> List[int]:

        left = 0
        right = len(numbers) - 1

        while left < right:

            curr_sum = numbers[left] + numbers[right]

            # Found the required pair
            if curr_sum == target:
                return [left + 1, right + 1]

            # Need a larger sum
            elif curr_sum < target:
                left += 1

            # Need a smaller sum
            else:
                right -= 1
```

### Complexity

```text
Time  : O(N)

Space : O(1)
```

Each pointer moves at most **N** times.

# Key Interview Takeaways

* **Pattern:** Two Pointers
* **Key Observation:** The array is already **sorted**.
* **Invariant:** `left < right`, and moving pointers changes the sum predictably.
* **Rule:**

  * Sum < target → `left++`
  * Sum > target → `right--`
  * Sum == target → return answer
* **Complexity:** **O(N)** time and **O(1)** extra space.
