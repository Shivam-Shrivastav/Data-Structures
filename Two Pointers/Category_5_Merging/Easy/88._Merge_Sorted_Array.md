# Merge Sorted Array (LeetCode 88)

**Pattern:** Two Pointers (Backward Merge)

---

# 1. Problem Statement

You are given two integer arrays:

* `nums1` of size `m + n`, where:

  * The first `m` elements are sorted.
  * The last `n` elements are `0`s and should be ignored (extra space).
* `nums2` of size `n`, sorted.

Merge `nums2` into `nums1` so that `nums1` becomes one sorted array.

The merge **must be done in-place**.

### Constraints

* `0 <= m, n <= 200`
* `nums1.length == m + n`
* `nums2.length == n`
* Arrays are sorted in non-decreasing order.

# 4. Intuition & Pattern Recognition

### Signals

Whenever you see

* Two sorted arrays
* Merge them
* In-place
* Extra space available at the end of one array

Think:

> **Two Pointers from the Back**

### Why not merge from the front?

Suppose

```text
nums1

1 2 3 0 0 0
```

If you place elements from the front,

you overwrite values that haven't been processed yet.

You'll need shifting.

That becomes O(N²).

### Why merge from the back?

The end of `nums1` is empty.

We can safely place the largest remaining element there.

No element gets overwritten.

### Interview Thinking

```text
Both arrays are sorted.

Largest element is at one of their ends.

The destination also has free space at the end.

So compare from the back and fill backwards.
```

# 7. Optimal Solution (Backward Two Pointers)

### Idea

Maintain three pointers

```text
i = last valid element in nums1

j = last element in nums2

k = last position in nums1
```

Always place the larger element at `k`.

Move the corresponding pointer.

---

### Python

```python
class Solution:
    def merge(self, nums1, m, nums2, n):

        i = m - 1          # Last valid element in nums1
        j = n - 1          # Last element in nums2
        k = m + n - 1      # Last position in nums1

        # Merge while both arrays have elements
        while i >= 0 and j >= 0:

            if nums1[i] > nums2[j]:
                nums1[k] = nums1[i]
                i -= 1
            else:
                nums1[k] = nums2[j]
                j -= 1

            k -= 1

        # Copy remaining nums2 elements (if any)
        while j >= 0:
            nums1[k] = nums2[j]
            j -= 1
            k -= 1
```

### Complexity

```text
Time  : O(m+n)

Space : O(1)
```

# Key Interview Takeaways

* **Pattern:** Two Pointers (Backward Merge).
* **Key Insight:** Merge from the **end** to avoid overwriting unprocessed elements.
* **Pointers:** `i` → last valid element in `nums1`, `j` → last element in `nums2`, `k` → last position in `nums1`.
* **Rule:** Place the larger of `nums1[i]` and `nums2[j]` at `nums1[k]`.
* **Important Edge Case:** If `nums2` still has elements after `nums1` is exhausted, copy them. If `nums1` has remaining elements, they are already in the correct position.
* **Complexity:** **O(m+n)** time and **O(1)** extra space.
