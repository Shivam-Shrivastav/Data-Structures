# Interval List Intersections (LeetCode 986)

**Pattern:** Two Pointers (Intervals)

---

# 1. Problem Statement

You are given two lists of **closed intervals**:

* `firstList`
* `secondList`

Each list is:

* Sorted by start time.
* Pairwise disjoint (intervals within the same list do not overlap).

Return the **intersection of these two interval lists**.

An interval `[a, b]` intersects `[c, d]` if they overlap.

The intersection is:

```text
[max(a, c), min(b, d)]
```

if

```text
max(a, c) <= min(b, d)
```

### Constraints

* `0 <= firstList.length, secondList.length <= 1000`
* `firstList[i].length == secondList[i].length == 2`
* Intervals are sorted and non-overlapping.

# 4. Intuition & Pattern Recognition

### Signals

Whenever you see

* Two sorted interval lists
* Compare intervals
* Find overlap

Think

> **Two Pointers**

### Key Observation

At any moment, only one interval from each list matters.

Suppose

```text
A = [2,8]

B = [5,10]
```

Overlap starts at

```text
max(2,5) = 5
```

Overlap ends at

```text
min(8,10) = 8
```

Result

```text
[5,8]
```

### Which pointer should move?

Suppose

```text
A ends at 8

B ends at 10
```

After processing,

A can never overlap future intervals because it already ended first.

So move A.

Rule:

```text
Smaller ending interval

↓

Move that pointer
```

### Interview Thinking

```text
Both interval lists are sorted.

Compute overlap.

If overlap exists, save it.

The interval that ends earlier
cannot overlap future intervals.

Move that pointer.
```

# 7. Optimal Solution (Two Pointers)

### Idea

Maintain

```text
i -> firstList

j -> secondList
```

For each pair

Compute

```text
start = max(start1, start2)

end = min(end1, end2)
```

If

```text
start <= end
```

there is an intersection.

Move the interval that finishes first.

---

### Python

```python
class Solution:
    def intervalIntersection(self, firstList, secondList):

        i = 0
        j = 0

        ans = []

        while i < len(firstList) and j < len(secondList):

            # Compute overlap
            start = max(firstList[i][0], secondList[j][0])
            end = min(firstList[i][1], secondList[j][1])

            # Valid intersection
            if start <= end:
                ans.append([start, end])

            # Move the interval that ends first
            if firstList[i][1] < secondList[j][1]:
                i += 1
            else:
                j += 1

        return ans
```

### Complexity

```text
Time  : O(M + N)

Space : O(1)
```

(Excluding the output array.)

# Key Interview Takeaways

* **Pattern:** Two Pointers on Sorted Intervals.
* **Key Formula:** An overlap exists if `max(start1, start2) <= min(end1, end2)`.
* **Intersection:** `[max(start1, start2), min(end1, end2)]`.
* **Pointer Rule:** Always move the interval with the **smaller end value**, because it cannot overlap with future intervals.
* **Complexity:** **O(M + N)** time and **O(1)** extra space (excluding the output list).
