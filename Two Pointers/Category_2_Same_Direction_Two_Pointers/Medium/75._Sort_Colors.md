# Sort Colors (LeetCode 75)

**Pattern:** Three Pointers (Dutch National Flag Algorithm)

---

# 1. Problem Statement

Given an array `nums` containing only:

* `0` → Red
* `1` → White
* `2` → Blue

Sort the array **in-place** so that all `0`s come first, followed by all `1`s, then all `2`s.

You **cannot** use the library sort function.

### Constraints

* `1 <= nums.length <= 300`
* `nums[i]` is either `0`, `1`, or `2`
* Must solve in **O(N)** time and **O(1)** extra space.

# 7. Optimal Solution (Dutch National Flag)

### Idea

Maintain:

* `low` → next position for `0`
* `mid` → current element
* `high` → next position for `2`

Rules:

* If `nums[mid] == 0`

  * Swap with `low`
  * `low++`
  * `mid++`

* If `nums[mid] == 1`

  * Already in correct region
  * `mid++`

* If `nums[mid] == 2`

  * Swap with `high`
  * `high--`
  * **Do NOT increment `mid`**

---

### Why don't we increment `mid` after swapping with `high`?

Because the element coming from the end is **unknown**.

It could be:

* 0
* 1
* 2

It must be checked again.

---

### Python

```python
class Solution:
    def sortColors(self, nums: List[int]) -> None:

        low = 0
        mid = 0
        high = len(nums) - 1

        while mid <= high:

            if nums[mid] == 0:

                nums[low], nums[mid] = nums[mid], nums[low]
                low += 1
                mid += 1

            elif nums[mid] == 1:

                mid += 1

            else:

                nums[mid], nums[high] = nums[high], nums[mid]
                high -= 1
```

### Complexity

```text
Time  : O(N)

Space : O(1)
```

Every element is processed at most once.

# Key Interview Takeaways

* **Pattern:** Dutch National Flag (Three Pointers).
* **Pointers:**

  * `low` → boundary for 0s
  * `mid` → current element
  * `high` → boundary for 2s
* **Invariant:**

  * `0 ... low-1` → all 0s
  * `low ... mid-1` → all 1s
  * `mid ... high` → unknown
  * `high+1 ... n-1` → all 2s
* **Critical Rule:** After swapping with `high`, **do not increment `mid`**, because the incoming element is unprocessed.
* **Complexity:** **O(N)** time, **O(1)** space.
