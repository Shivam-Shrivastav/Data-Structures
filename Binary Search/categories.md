## KEY PATTERNS TO MASTER:

### 1. Classic Binary Search Template
```python
def binarySearch(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

### 2. Left Boundary (First Position)
```python
def firstPosition(nums, target):
    left, right = 0, len(nums) - 1
    result = -1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            result = mid
            right = mid - 1  # continue searching left
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return result
```

### 4. Rotated Array Search
```python
def searchRotated(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        # left half is sorted
        if nums[left] <= nums[mid]:
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        # right half is sorted
        else:
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return -1
```

## IMPORTANT NOTES:

- **Integer Overflow**: Use `mid = left + (right - left) // 2` instead of `(left + right) // 2`
- **Binary Search on Answer**: when you can't search on array directly, search on range of answers
- **Feasibility Function**: The key to solving minimization/maximization problems
- **Monotonicity**: Ensure the search space is monotonic (if something works, everything beyond/under works)
- **Boundary Conditions**: Be careful with inclusive/exclusive bounds
- **Duplicates**: Handle when searching with duplicates (use left/right bounds carefully)

This progression will take you from basic binary search to solving complex optimization problems!
